A. Before you start (from nothing)

What you will end up with

  • Camera web UI on http://41.74.144.221:8090 (MJPEG stream, PTZ, login)
  • Optional decoder on host ports 18080 (HTTP) and 18554 (RTSP) when using the real compose profile
  • Grafana untouched at https://41.74.144.221:8081

What you need ready

  • V380 device ID: 89370567 (already the default in .env.example)
  • Device username: admin (default)
  • Camera password: you type it only in the terminal when prompted — never on this page
  • ACCESS_TOKEN: invent a strong unique secret yourself (used for web UI login). Type it only in the terminal

PC requirements

  • Linux or Windows on host 41.74.144.221
  • Internet access (to pull the repo / images)
  • Ability to open a terminal on that PC (SSH, RDP console, or local)

Software to install if missing

Prefer Docker with Compose plugin. Or use Git and Node 18+.

sudo apt update && sudo apt install -y docker.io docker-compose-v2
# If docker-compose-v2 is unavailable, try the Compose plugin:
# sudo apt install -y docker.io docker-compose-plugin
sudo usermod -aG docker "$USER"   # then log out/in
docker --version && docker compose version
sudo apt update && sudo apt install -y git curl
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs

npm -v

# Option B: install Node.js LTS from https://nodejs.org/ and Git from https://git-scm.com/
# Then open PowerShell as a normal user on 41.74.144.221

Port double-check (mandatory)

Do this before binding and again after install. Confirm 8090 is free before the camera stack binds it, and confirm 8081 is still Grafana. Live URL http://41.74.144.221:8090 is valid only after install claims that free port.

Before install — confirm 8090 free + 8081 is Grafana

ss -ltn | grep -E ':(8081|8090|18080|18554)' || true
# Expect: something on 8081 (Grafana). Expect: nothing on 8090 (free to claim).
curl -sk https://127.0.0.1:8081/api/health || curl -s http://127.0.0.1:8081/api/health
# Pass: health JSON / OK. Fail: refused — stop and do not reclaim 8081.
bash scripts/safety-check.sh --before
# or: curl one-shot from README / Step 2

After install — confirm camera on 8090, Grafana still on 8081

ss -ltn | grep -E ':(8081|8090|18080|18554)' || true
# Expect: 8081 still present + 8090 now listening (camera). 18080/18554 if real profile.
curl -sk https://127.0.0.1:8081/api/health || curl -s http://127.0.0.1:8081/api/health
curl -s http://127.0.0.1:8090/health
# Pass: JSON ok/status. Then open http://41.74.144.221:8090

http://41.74.144.221:8090

Never bind the camera UI to 8081. If 8090 is unexpectedly busy, pick another free port via PORT= — do not displace Grafana.

B. Installation (step-by-step)

Ports used: web 8090, decoder HTTP 18080, RTSP 18554. Never use 8081 (Grafana).

  1. Step 0 — Grafana stays on 8081

    Leave Grafana alone. Do not stop, rebind, or reclaim port 8081.

    https://41.74.144.221:8081

    Camera stack will bind 0.0.0.0:8090 so the LAN/public UI is:

    http://41.74.144.221:8090

  2. Step 1 — Open a terminal on 41.74.144.221

    SSH, RDP console, or local terminal on the machine with IP 41.74.144.221.

    ssh user@41.74.144.221

  3. Step 2 — Preflight safety-check (--before) + Port double-check

    Before binding: confirm 8090 is free and 8081 is still Grafana. Run Port double-check (ss -ltn | grep -E ':(8081|8090|18080|18554)' + Grafana /api/health), then:

    cd ~/v380-web-camera
bash scripts/safety-check.sh --before
    curl -fsSL https://raw.githubusercontent.com/LeeMcQ/v380-web-camera/main/scripts/safety-check.sh | bash -s -- --before
    irm https://raw.githubusercontent.com/LeeMcQ/v380-web-camera/main/scripts/safety-check.ps1 | iex
# or after clone:
.\scripts\safety-check.ps1 -Before

  4. Step 3 — Easy one-line install

    Prefers Docker Compose; falls back to Node.js ≥ 18. Idempotent (safe to re-run).

    curl -fsSL https://raw.githubusercontent.com/LeeMcQ/v380-web-camera/main/scripts/easy-install.sh | bash
    irm https://raw.githubusercontent.com/LeeMcQ/v380-web-camera/main/scripts/easy-install.ps1 | iex

  5. Step 4 — Terminal prompts for CAMERA_PASSWORD + ACCESS_TOKEN

    When the installer prompts in the terminal only:

    • CAMERA_PASSWORD — V380 camera password (needed for real stream / decoder profile)
    • ACCESS_TOKEN — strong unique secret you invent for web UI login

    Never paste passwords into this website (or any Pages / docs page). Secrets are written only to ~/v380-web-camera/.env on the PC (gitignored). Never commit .env.

  6. Step 5 — Optional manual path (if one-liner fails)

    git clone https://github.com/LeeMcQ/v380-web-camera.git
cd v380-web-camera
cp .env.example .env
# Edit .env in the terminal only — set CAMERA_PASSWORD and a strong ACCESS_TOKEN
# nano .env   # or: notepad .env on Windows
    docker compose --profile real up --build -d
    npm install
npm start
# With MOCK_CAMERA=0 you must also run a V380 decoder reachable at DECODER_URL
# (default http://127.0.0.1:18080). Compose profile "real" starts both for you.

  7. Step 6 — Firewall TCP 8090

    Allow inbound TCP 8090 so other devices can reach the UI. Open TCP 18080 only if you need decoder HTTP from outside the PC (usually not — the web container talks to the decoder on the Docker network).

    sudo ufw allow 8090/tcp comment 'v380-web-camera'
# optional: sudo ufw allow 18080/tcp
sudo ufw status

    Do not change Grafana’s 8081 firewall rules unless you intend to.

  8. Step 7 — Open the live UI and log in

    http://41.74.144.221:8090

    Log in with the ACCESS_TOKEN you set in the terminal. Local-only check: http://127.0.0.1:8090.

C. Installation and checks

Full verification checklist. Run on the PC after install. Each item is pass/fail.

  1. Ports listening pass / fail

    8081 still up (Grafana). Plus 8090 (camera UI). Plus 18080 if using the real profile.

    ss -ltn | grep -E ':(8081|8090|18080|18554)' || true
    netstat -an | findstr "8081 8090 18080 18554"

  2. Grafana health still OK

    curl -sk https://127.0.0.1:8081/api/health || curl -s http://127.0.0.1:8081/api/health

  3. Camera GET /health on :8090

    curl -s http://127.0.0.1:8090/health
# Pass: JSON with ok/status and mode "real" or "mock".

  4. Unauthenticated stream returns 401

    curl -s -o /dev/null -w '%{http_code}\n' http://127.0.0.1:8090/stream.mjpg
# Pass: prints 401.

  5. Authenticated snapshot / session (Bearer)

    Replace YOUR_TOKEN with the ACCESS_TOKEN you set locally — never paste the real value into this site.

    curl -s -o /dev/null -w '%{http_code}\n' -H "Authorization: Bearer YOUR_TOKEN" http://127.0.0.1:8090/api/snapshot
# Pass: 200.

curl -s -H "Authorization: Bearer YOUR_TOKEN" http://127.0.0.1:8090/api/session
# Pass: JSON session / controls.

  6. Browser smoke test

    • Open http://41.74.144.221:8090
    • Log in with ACCESS_TOKEN
    • See live feed; try PTZ buttons
    • Confirm feed times out around ~120s and reconnect works

  7. safety-check --after must pass

    bash ~/v380-web-camera/scripts/safety-check.sh --after
# Exits non-zero if Grafana was up before and is down after.

  8. Done criteria

    Install is complete when all of the following are true:
    • Grafana still healthy on :8081
    • Camera UI reachable on http://41.74.144.221:8090
    • GET /health returns ok (mode real or mock)
    • Unauthenticated /stream.mjpg returns 401
    • Login + live feed + PTZ work in the browser
    • safety-check --after exits 0
    • No real passwords / tokens committed or pasted into Pages

D. Troubleshooting

  • Port busy: do not steal 8081. Change PORT / decoder ports to other free values and re-run the Port double-check.
  • Weak token: empty / change-me binds 127.0.0.1 only by default — set a strong ACCESS_TOKEN for LAN/public :8090.
  • No video: check decoder, camera password (terminal/.env only), and MOCK_CAMERA.
  • Re-run installer: easy-install is idempotent and safe to re-run after fixing .env.
  • 8090 still closed from outside: open firewall TCP 8090; confirm process listens on 0.0.0.0:8090.

E. Security

  • Firewall: open inbound TCP 8090 only as needed; leave Grafana 8081 alone. Do not expose decoder 18080 unless required.
  • Strong ACCESS_TOKEN — replace change-me before exposing the UI. Empty / change-me logs a loud startup warning and binds 127.0.0.1 only (unless you override).
  • Auth: prefer HttpOnly cookie (POST /api/login) or Bearer. Discourage long-lived shared links with ?token=.
  • HTTPS if the UI is reachable on the public internet (reverse proxy / TLS).
  • Never commit .env — camera password and tokens stay on the PC only. Never paste secrets into this Pages site.
  • Rotate ACCESS_TOKEN (and camera password) if a token is leaked.
  • 120s stream timeout (STREAM_TIMEOUT_SEC) hard-stops MJPEG; the UI reconnects.
