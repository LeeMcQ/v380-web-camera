V380 Web Camera

Step-by-step install (this PC)

Ports used: web 8090, decoder HTTP 18080, RTSP 18554. Never use 8081 (Grafana).

  1. Step 0 — What stays as-is

    Leave Grafana alone. Do not stop, rebind, or reclaim port 8081.

    https://41.74.144.221:8081

    Camera stack will bind 0.0.0.0:8090 so the LAN/public UI is:

    http://41.74.144.221:8090

  2. Step 1 — SSH / open a terminal on that PC

    Log into the machine that has IP 41.74.144.221 (SSH, RDP console, or local terminal).

    ssh user@41.74.144.221

  3. Step 2 — Run safety check (before)

    Snapshot Grafana health and list ports 8081 / 8090 / 18080 / 18554.

    cd ~/v380-web-camera
bash scripts/safety-check.sh --before
    curl -fsSL https://raw.githubusercontent.com/LeeMcQ/v380-web-camera/main/scripts/safety-check.sh | bash -s -- --before
    irm https://raw.githubusercontent.com/LeeMcQ/v380-web-camera/main/scripts/safety-check.ps1 | iex
# or after clone:
.\scripts\safety-check.ps1 -Before

  4. Step 3 — One-line install

    Prefers Docker Compose; falls back to Node.js ≥ 18. Idempotent (safe to re-run). Secrets are entered only in the terminal prompts — never on this page.

    curl -fsSL https://raw.githubusercontent.com/LeeMcQ/v380-web-camera/main/scripts/easy-install.sh | bash
    irm https://raw.githubusercontent.com/LeeMcQ/v380-web-camera/main/scripts/easy-install.ps1 | iex

  5. Step 4 — Enter camera password + ACCESS_TOKEN

    When the installer prompts in the terminal:

    • CAMERA_PASSWORD — V380 camera password (needed for real stream / decoder profile)
    • ACCESS_TOKEN — shared secret for the web UI login (choose a strong unique value)

    Never paste passwords into this website (or any Pages / docs page). Secrets are written only to ~/v380-web-camera/.env on the PC (gitignored). Never commit .env.

  6. Step 5 — Open the live UI

    http://41.74.144.221:8090

    Log in with the ACCESS_TOKEN you set. Local-only check: http://127.0.0.1:8090.

  7. Step 6 — Post-install safety tests

    Confirm Grafana is still healthy, camera /health responds, and ports look right.

    bash ~/v380-web-camera/scripts/safety-check.sh --after
curl -s http://127.0.0.1:8090/health
curl -sk https://127.0.0.1:8081/api/health || curl -s http://127.0.0.1:8081/api/health
ss -ltn | grep -E ':(8081|8090|18080|18554)[[:space:]]' || true
    .\scripts\safety-check.ps1 -After

    Safety check exits non-zero if Grafana was up before and is down after.

  8. Step 7 — Firewall note

    Allow inbound TCP 8090 to reach the UI from other devices. Open TCP 18080 only if you need decoder HTTP from outside the PC (usually not required — web container talks to decoder on the Docker network).

    sudo ufw allow 8090/tcp comment 'v380-web-camera'
# optional: sudo ufw allow 18080/tcp
sudo ufw status

    Do not change Grafana’s 8081 firewall rules unless you intend to.

Security checklist

  • Firewall: open inbound TCP 8090 only as needed; leave Grafana 8081 alone. Do not expose decoder 18080 unless required.
  • Strong ACCESS_TOKEN — replace change-me before exposing the UI. Empty / change-me logs a loud startup warning and binds 127.0.0.1 only (unless you override).
  • Auth: prefer HttpOnly cookie (POST /api/login) or Bearer. Discourage long-lived shared links with ?token=.
  • HTTPS if the UI is reachable on the public internet (reverse proxy / TLS).
  • Never commit .env — camera password and tokens stay on the PC only. Never paste secrets into this Pages site.
  • Rotate ACCESS_TOKEN (and camera password) if a token is leaked.
  • 120s stream timeout (STREAM_TIMEOUT_SEC) hard-stops MJPEG; the UI reconnects.
